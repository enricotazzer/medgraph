Cohort concept map

Each node is a concept: records with the same code, merged across patients. Node size and the number in brackets count patients with at least one such record. A link counts patients whose own record links the two concepts. Click a node or a link for its patients. Drag to move, scroll to zoom.

medgraph is a research prototype, not a medical device. The map shows what the records contain and how often; it does not describe any real population. Generated offline; this page makes no network requests.
