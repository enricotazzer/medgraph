## What this does not measure

- Whether a kept sentence is right: the checks catch invented numbers and dates, missing citations, diagnostic and treatment wording, and the wrong language. A sentence can cite the right item and still misread it, and numbers written as words are not checked.
- Quality of the Italian and of the plain-language register: the review file in the run folder shows every variant of some flags side by side, for a person to judge.
- The note check on real notes: that needs MIMIC-IV-Note, run locally.
